# Python Jukebox Application 

A desktop jukebox application developed using Python and Tkinter as part of my university Object-Oriented Programming coursework.

## Features
- View available tracks and track information
- Create and manage track playlists
- Update track information
- Graphical user interface developed using Tkinter

## Technologies
- Python
- Tkinter
- Object-Oriented Programming (OOP)
- Software testing and debugging

## Project Overview
This project demonstrates my understanding of object-oriented programming, graphical user interface development and modular application design.

The application is organised into multiple Python modules to separate functionality and improve code organisation.

## Development
Developed as part of my BSc Computing studies at the University of Greenwich.
